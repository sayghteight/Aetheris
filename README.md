Aetheria is a powerful, cross-platform desktop application designed specifically for fiction writers. It provides a complete environment for managing novels, short stories, and any narrative project — from the first draft to the final export.

## ✨ Features

### 📝 Manuscript Editor
- **Rich Text Editing** — Powered by TipTap (ProseMirror) with support for headings, bold, italic, underline, lists, blockquotes, and code
- **Scene Management** — Organize your manuscript with Parts, Chapters, and Scenes
- **Status Tracking** — Mark scenes as Draft, Review, or Final
- **Metadata** — Add synopses, author notes, and writing goals to each scene
- **Word Count & Stats** — Real-time word count and estimated reading time
- **Spell Check** — Built-in spell checking support
- **Split & Merge Scenes** — Divide long scenes or merge multiple scenes into one
- **Find & Replace** — Search and replace text across your manuscript

### 🌌 Universe Management
Keep all your worldbuilding organized in one place:
- **Characters** — Create and manage character profiles
- **Locations** — Track places in your story world
- **Items** — Objects and artifacts
- **Races** — Species and peoples
- **Organizations** — Groups, factions, and institutions
- **Notes & Research** — Freeform notes and research materials

### ⏱️ Timeline
- Create events with precise timestamps (year, month, day, hour, minute)
- Link events to calendar systems
- Associate events with manuscript scenes

### 📅 Custom Calendars
- Define your own calendar systems with custom months, days per week, and era names
- Perfect for fantasy and science fiction worlds with non-standard time systems

### 📤 Export System
Export your manuscript in multiple formats:
- **PDF** — Print-ready documents
- **DOCX** — Microsoft Word compatible
- **HTML** — For web publishing
- **Markdown** — For use with other writing tools
- **TXT** — Plain text

Export options include:
- Include/exclude scene titles, chapter titles, part titles
- Include synopses and author notes
- Select specific scenes or export everything

### 📥 Word Import
Import existing `.docx` documents directly into your manuscript structure

### 🎨 Themes & Appearance
Multiple themes to suit your preference:
- **Midnight** — Dark theme (default)
- **Aurora** — Warm dark theme with amber accents
- **Noir** — Deep dark theme

Focus modes:
- **Standard** — Normal interface
- **Focus** — Reduced distractions
- **Distraction-Free** — Clean black background

### 🌐 Internationalization
Available in English and Spanish

## 📋 Requirements

- **Windows 10/11** (x64)
- **macOS 10.15+** (Apple Silicon or Intel)
- **Linux** (Ubuntu 18.04+, Fedora 30+)

## 🛠️ Development

### Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS 4
- **Backend**: Tauri 2 (Rust)
- **Editor**: TipTap (ProseMirror-based)
- **State Management**: Zustand
- **Database**: SQLite (via rusqlite)
- **Export**: PrintPDF (PDF), mammoth (DOCX), marked (HTML/Markdown)

### Prerequisites

- Node.js 18+
- Rust 1.70+
- npm or pnpm

### Setup

```bash
# Clone the repository
git clone https://github.com/sayghteight/culto-guieditor.git
cd culto-guieditor

# Install dependencies
npm install

# Run in development mode
npm run tauri dev
```

### Building

```bash
# Build for production
npm run tauri build
```

The built executables will be in `src-tauri/target/release/` (or `debug/` for debug builds).

### Project Structure

```
culto-guieditor/
├── src/                          # React frontend
│   ├── components/               # Shared UI components
│   ├── features/                 # Feature modules
│   │   ├── editor/              # TipTap manuscript editor
│   │   ├── export/              # Export panel
│   │   ├── import/              # Word import
│   │   ├── manuscript/          # Manuscript tree view
│   │   └── project/             # Project setup, settings, universe, timeline, calendars
│   ├── hooks/                    # Custom React hooks
│   ├── i18n/                    # Internationalization (English & Spanish)
│   ├── store/                   # Zustand state stores
│   └── utils/                   # Utility functions
├── src-tauri/                    # Rust backend
│   ├── src/
│   │   ├── commands/            # Tauri commands (IPC)
│   │   ├── database/             # SQLite database operations
│   │   ├── domain/              # Domain models
│   │   ├── export/              # Export modules (PDF, DOCX, HTML, Markdown, TXT)
│   │   └── state.rs             # Application state
│   └── icons/                   # Application icons
└── package.json
```
